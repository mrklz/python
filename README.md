# Python Programming Solutions

Репозиторий содержит коллекцию скриптов на языке Python, включающую в себя решения олимпиадных задач с платформы Codeforces, а также практические упражнения из сборника «1000 задач по программированию».

## Структура проекта

<pre>
python/
├── 1000_zadach_po_programmirovaniju/  # Задачи из учебного сборника
│   └── ...                            # (Скрипты с базовыми алгоритмами)
└── codeforces/                        # Решения задач с Codeforces
    └── ...                            # (Олимпиадные задачи на Python)
</pre>

## Описание разделов

* **1000_zadach_po_programmirovaniju/** — Практические упражнения для освоения базовых концепций программирования на Python (работа с переменными, ветвлениями, циклами, списками и функциями).
* **codeforces/** — Решения алгоритмических и олимпиадных задач с популярной платформы Codeforces, оптимизированные под синтаксис Python.

## Как запустить

Для запуска программ вам понадобится установленный интерпретатор Python версии 3.x.

1. Склонируйте репозиторий:
git clone https://github.com

2. Перейдите в папку с нужным решением:
cd python/codeforces

3. Запустите скрипт:
python script_name.py

## Требования

* Интерпретатор Python 3.8 или выше
* Текстовый редактор (VS Code, PyCharm, Sublime Text)
